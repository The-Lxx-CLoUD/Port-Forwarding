۱. ngrok چیست؟

ngrok ابزاری‌ست که یک تونل امن از یک آدرس عمومی روی اینترنت (یک URL یا یک آدرس TCP) مستقیماً به یک سرویس که روی سیستم خودت اجرا شده وصل می‌کنه — حتی اگه سیستمت پشت NAT باشه، فایروال داشته باشه، یا اصلاً آی‌پی عمومی نداشته باشه. کاربردهای رایجش:

  • تست وبهوک‌ها (Stripe، GitHub، ربات تلگرام و...) روی یه سرور توسعه‌ی لوکال
  • اشتراک‌گذاری موقت یه اپ وب لوکال با یه مشتری یا همکار
  • اکسپوز کردن یه API لوکال برای تست اپ موبایل
  • فوروارد کردن سرویس‌های TCP مثل SSH، سرور بازی، یا سوکت اختصاصی
  • دسترسی سریع ریموت به یه دستگاه بدون نیاز به تنظیم port-forwarding روی روتر

به‌طور خلاصه: ngrok یه ایجنت روی سیستمت اجرا می‌کنه. این ایجنت یه اتصال خروجی به سرورهای ابری ngrok باز می‌کنه. ترافیکی که به URL عمومی ngrok می‌رسه، از سرورهای ngrok عبور می‌کنه و از همون اتصال خروجی به پورت لوکال تو برمی‌گرده. چون اتصال از سمت تو (خروجی) شروع میشه، نیازی به باز کردن هیچ پورتی روی روتر یا فایروال نداری.

۲. نصب ngrok

ویندوز

  1. به آدرس https://ngrok.com/download برو و نسخه‌ی ویندوز رو دانلود کن.
  2. فایل زیپ رو باز کن — یه فایل تنها به اسم ngrok.exe بهت میده.
  3. اونو یه‌جای مناسب مثل C:\ngrok\ngrok.exe بذار و اختیاری اون پوشه رو به PATH اضافه کن تا از هر جای ترمینال بتونی ngrok رو صدا بزنی.

یا با پکیج‌منیجر:

choco install ngrok
# یا
winget install ngrok.ngrok

مک (macOS)

brew install ngrok/ngrok/ngrok

لینوکس (Debian/Ubuntu)

curl -sSL https://ngrok-agent.s3.amazonaws.com/ngrok.asc \
  | sudo tee /etc/apt/trusted.gpg.d/ngrok.asc >/dev/null
echo "deb https://ngrok-agent.s3.amazonaws.com buster main" \
  | sudo tee /etc/apt/sources.list.d/ngrok.list
sudo apt update && sudo apt install ngrok

لینوکس (باینری عمومی — روی هر توزیعی کار می‌کنه)

curl -O https://bin.equinox.io/c/bNyj1mQVY4c/ngrok-v3-stable-linux-amd64.tgz
tar -xvzf ngrok-v3-stable-linux-amd64.tgz
sudo mv ngrok /usr/local/bin/

برای اطمینان از نصب صحیح:

ngrok version

۳. ساخت حساب کاربری و گرفتن Authtoken

  1. به https://dashboard.ngrok.com/signup برو و یه حساب رایگان بساز (با ایمیل، گوگل یا گیت‌هاب).
  2. بعد از لاگین، از منوی سمت چپ روی «Your Authtoken» کلیک کن (زیر بخش Getting Started).
  3. توکنی که اونجا نشون داده میشه رو کپی کن — یه رشته‌ی طولانیه مخصوص حساب تو. باهاش مثل یه پسورد رفتار کن؛ هرکی این توکن رو داشته باشه می‌تونه با حساب تو تونل باز کنه.

پلن رایگان برای تقریباً همه‌ی چیزایی که تو این راهنما هست کافیه: تونل HTTP/TCP، یه دامنه‌ی ثابت، و چند تونل هم‌زمان.

۴. وصل کردن Authtoken

قبل از اینکه ngrok بتونه تونل باز کنه، باید بدونه تو کی هستی. این دستور رو یه بار اجرا کن (لوکال ذخیره میشه، فقط یه بار در هر سیستم لازمه): 

ngrok config add-authtoken YOUR_TOKEN_HERE

این دستور توکن رو توی فایل کانفیگ ngrok می‌نویسه، که معمولاً اینجاست:

  • لینوکس/مک: ~/.config/ngrok/ngrok.yml
  • ویندوز: %HOMEPATH%\AppData\Local\ngrok\ngrok.yml

۵. استفاده پایه — اکسپوز کردن یک سرور HTTP

فرض کن یه اپ وب لوکال روی پورت 3000 داری (ری‌اکت، فلسک، اکسپرس، هرچی). برای اینکه به اینترنت عمومی اکسپوزش کنی: 

ngrok http 3000

ngrok یه داشبورد توی ترمینال نشون میده، چیزی شبیه این:

Session Status                online
Account                       you@example.com (Plan: Free)
Version                       3.x.x
Region                        United States (us)
Forwarding                    https://a1b2-203-0-113-5.ngrok-free.app -> http://localhost:3000

Connections                   ttl     opn     rt1     rt5     p50     p90
                               0       0       0.00    0.00    0.00    0.00

هر کسی اون آدرس https://...ngrok-free.app رو باز کنه، به پورت 3000 سیستم تو می‌رسه، فارغ از اینکه سیستمت فیزیکاً کجاست. با Ctrl+C تونل رو ببند — آدرس بلافاصله از کار می‌افته.

حالت‌های رایج دیگه:

ngrok http 3000 --domain=myapp.ngrok-free.app   # استفاده از دامنه‌ی ثابت (بخش ۸)
ngrok http https://localhost:8443                # فوروارد به یه سرور HTTPS لوکال
ngrok http 3000 --basic-auth="user:password"      # اضافه کردن رمز پایه جلوی تونل

۶. اکسپوز کردن سرویس‌های TCP (مثل SSH یا سوکت اختصاصی)

تونل HTTP فقط برای ترافیک وب کار می‌کنه. برای هر چیز دیگه‌ای — SSH، یه سرور سوکت پایتون اختصاصی (مثل همون اسکریپت کلاینت/سروری که قبلاً تنظیم کردی)، سرور ماینکرفت، دیتابیس و غیره — از تونل TCP استفاده کن: 

ngrok tcp 22          # مثلاً اکسپوز کردن SSH لوکال
ngrok tcp 1080        # اکسپوز کردن سرویس اختصاصی روی پورت ۱۰۸۰

خروجی اینجوری چیزیه:

Forwarding    tcp://4.tcp.ngrok.io:14837 -> localhost:1080

یعنی هر کسی (یا هر اسکریپت کلاینتی) که به 4.tcp.ngrok.io روی پورت 14837 وصل بشه، به‌صورت شفاف به پورت 1080 سیستم تو فوروارد میشه. توی همون اسکریپت کلاینت/سروری که قبلاً تنظیم کردی، مقادیر رو اینجوری می‌ذاری: 

RHOST = "4.tcp.ngrok.io"
RPORT = 14837
توجه: توی پلن رایگان، آدرس و پورت TCP هر بار که تونل رو استارت می‌کنی به‌صورت تصادفی تخصیص داده میشه (مگر اینکه یه آدرس TCP ثابت رزرو کنی — بخش ۸ رو ببین).

۷. فایل کانفیگ ngrok.yml

به‌جای تایپ کردن فلگ‌ها هر بار، می‌تونی تونل‌های نام‌گذاری‌شده رو توی یه فایل کانفیگ تعریف کنی و چندتاشو با هم استارت بزنی. مسیر فایل کانفیگت رو با این دستور پیدا کن: 

ngrok config check

نمونه‌ی یه فایل کانفیگ:

version: "2"
authtoken: YOUR_TOKEN_HERE
tunnels:
  webapp:
    proto: http
    addr: 3000
  ssh:
    proto: tcp
    addr: 22
  mysocket:
    proto: tcp
    addr: 1080

استارت زدن همه‌ی تونل‌های تعریف‌شده در فایل، یهجا:

ngrok start --all

یا استارت زدن فقط یه تونل خاص:

ngrok start webapp

۸. دامنه و آدرس ثابت (Static)

به‌طور پیش‌فرض، هر بار که ngrok رو استارت می‌کنی یه URL/آدرس تصادفیِ جدید می‌گیری. اگه بخوای یه آدرس ثابت داشته باشی که هیچوقت عوض نشه:

دامنه‌ی ثابت HTTP (پلن رایگان یکی بهت میده):

  1. توی داشبورد به بخش Domains برو و روی New Domain کلیک کن تا یه دامنه‌ی رایگان xxxx.ngrok-free.app رزرو کنی (یا توی پلن پولی دامنه‌ی خودتو وصل کن).
  2. موقع استارت زدن تونل ازش استفاده کن:
ngrok http 3000 --domain=your-name.ngrok-free.app

آدرس ثابت TCP (پلن‌های پولی):

ngrok tcp 1080 --remote-addr=1.tcp.ngrok.io:12345

۱۰. نکات امنیتی

  • authtoken خودتو هیچوقت جایی به‌صورت عمومی به اشتراک نذار (مثلاً توی یه ریپوی گیت‌هاب یا اسکرین‌شات) — چون کنترل کامل حساب ngrok تو رو میده.
  • برای هر تونل HTTP که چیز حساسی رو اکسپوز می‌کنه، از --basic-auth استفاده کن، چون URL عمومی قابل حدس زدن و اسکن‌شدنه.
  • فقط دقیقاً همون پورتی رو فوروارد کن که لازم داری — کل شبکه‌ی سیستمت رو تونل نکن.
  • وقتی کارت با تست تموم شد، تونل رو ببند (Ctrl+C)؛ روشن گذاشتنش یعنی اون سرویس همچنان به اینترنت اکسپوز باقی می‌مونه.
  • برای هر چیز طولانی‌مدت یا مربوط به پروداکشن، به‌جای اینکه یه تونل شخصی ngrok دائماً باز بذاری، از یه ریورس‌پروکسی درست‌وحسابی با TLS و قوانین فایروال استفاده کن.
یه تونل عمومی — چه HTTP چه TCP — هر چیزی که فوروارد می‌کنی رو در دسترس هر کسی روی اینترنت قرار میده، نه فقط افرادی که لینکشو بهشون میدی. سرویسی با پسورد پیش‌فرض یا ضعیف رو اکسپوز نکن.
